# 系统接口

本文件记录挂载在应用根路径上的系统级接口。

### 获取服务健康状态

**接口描述**

用于检查后端服务是否已启动并可正常响应。

**请求路径**

`GET /health`

**路径参数**

无。

**请求参数**

无。

**返回示例**

```json
{
  "status": "ok"
}
```

**返回参数**

| 参数名 | 参数类型 | 是否必需 | 参数说明及示例值 |
| --- | --- | --- | --- |
| status | string | 是 | 服务状态标识，当前固定为 `ok`。 |

**所需权限**

无需登录。

**其他说明**

该接口不依赖 `/api` 前缀，通常用于容器探活和启动后快速连通性检查。
