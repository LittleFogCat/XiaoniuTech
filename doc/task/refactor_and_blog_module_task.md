# 项目重构及博客模块开发任务

## 任务描述及目标

- 用户模块负责用户登录、注册、个人信息管理等功能。目前已实现用户的注册与登录功能，但与 Chat 模块耦合严重。需要优化用户模块，使其独立独立于 Chat 模块。
- 网站的核心应是全面的个人网站，而非仅限于 Chat 功能。
- 根据 [create_blog_module.md](create_blog_module.md) 中的描述，开发博客模块应负责用户博客的发布、管理等功能。

## UI guide

- 首页 UI 无需改动，也不需要显示用户相关信息。
- Chat 模块需新增返回主页按钮。
- 博客模块 UI 风格需要与主页和 Chat 模块保持一致。
