# 博客模块开发任务

## 基本目标

- 开发博客模块，负责展示和管理个人博客文章。
- 访问路径：`/blog`；该路径当前是外链访问，开发完毕后应链接至博客模块。

## 功能描述

### Header

- Header固定在顶部，在首页、文章详情页展示。
- 显示博客名称（XN Blog）、搜索栏、返回主页按钮、“写博客”按钮（仅登录用户可见）。

### 首页

- 主分区显示博客文章列表，包括标题、摘要和发布日期。
- 支持分页，每页显示 20 篇文章。
- 提供搜索功能，允许用户根据关键词搜索文章。
- 侧边栏展示个人信息、标签合集等内容。
- 个人基本信息，包括名称（XiaoNiu）、文章数、总字数、个人简介等。
- 提供基于标签的合集列表，每个合集包含该标签下的所有文章。

### 文章详情页

- 显示文章的完整内容，主分区包括标题、发布日期、正文、标签、阅读量等。
- 提供编辑按钮（仅文章发布者可见），点击后跳转到文章新建/编辑页。
- 支持评论功能，用户可以在文章下发表评论。评论必须登录才能发表。
- 显示文章的评论列表，包括评论者、评论内容、评论时间等。

### 文章新建/编辑页

- 点击 Header 中的写博客按钮，或在文章详情页点击编辑按钮，跳转到文章新建/编辑页。
- 仅允许登录用户进行文章新建/编辑操作；仅允许文章发布者进行编辑。
- 支持 markdown 形式的文章编辑功能。左侧从上至下为文章标题、工具栏（包括标签、保存按钮、发布按钮）、文章内容，右侧为实时预览区域。

## 技术要求

沿用本项目的技术栈与 UI 风格进行开发。具体参考 [README.md](../../README.md) 以及其它文档。
