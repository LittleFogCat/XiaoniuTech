# 首页改造和用户体验优化任务

## 任务描述

1. 首页改造：目前 [首页](../../frontend/src/pages/HomePage.jsx) 的布局和交互都比较简单，需要进行改造。
2. 支持全局国际化功能：需要支持中英文切换，并预留其他国际化扩展空间。
3. 支持全局浅色/深色模式切换功能：需要支持浅色/深色模式切换。
4. 优化人格的配置方式：从文件解析到通过 json 配置。

## 任务要求

### 首页 UI 优化

- Hero 部分从卡片布局改造成宽幅全屏布局。
- 去除“做简洁、好用、持续进化的数字产品。”的描述，改为“XiaoNiu Tech”。
- 去除联系方式卡片。联系方式放到首页底部，通过并排小图标的方式横向排布在 `BUILT BY LITTLEFOGCAT` 右侧。
- 首页增加透明 header，且在滚动时固定在顶部。header 内容包括标题、中英文切换按钮、浅色/深色模式切换按钮、登录/注册按钮。

### 国际化和颜色模式

- 将整个项目中，所有 UI 中硬编码的字符串，都通过国际化功能实现语言切换。支持简体中文、繁体中文、英文。
- 增加深色/浅色模式的切换。一旦切换，整个项目的所有页面风格都会切换，包括首页和各个子页面。

### 人格配置优化

人格文件从直接解析 md 文件，改为通过 `/conf/backend/identities/identities.json` 配置。`identities.json` 为一个 JSON 数组，包含了所有人格的配置。其中，`name` 为人格的名称，`desc` 为人格的描述，`persona` 为人格的定义，对应了 `persona` 目录下的同名 md 文件。例如，我已经在 `identities.json` 中给出了一个名称为 `小奶茉` 的人格示例，其对应的人格定义文件为 `/conf/backend/identities/persona/小奶茉.md`。
