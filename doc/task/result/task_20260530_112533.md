3. 在 `frontend/src/contexts/AppShellContext.jsx` 中补齐 `stock` 词典，覆盖简中、繁中、英文三套文案。

5. 将 `backend/src/routes/stock.js` 从 `requirePermission` 直接返回 HTTP 错误码，改为路由内统一输出 `{ code, success, msg, data }`。
6. 将 `frontend/src/services/stockApi.js` 改为按 envelope 解析 `data/msg`，避免继续依赖旧式 `res.ok + plain json` 结构。
7. 更新 `doc/apis/stock.md`，使股票接口文档对齐 API 规范：省略 `/api` 前缀说明、统一 envelope 示例、错误 code 说明。
