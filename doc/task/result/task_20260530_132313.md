# 任务归档

## 任务来源

- 需求文档：`doc/task/stock_review_problems2.md`

## 任务计划

1. 重构后端 stock 模型与校验逻辑，切换到新复盘结构。
2. 放开复盘列表与详情的游客读取路径。
3. 改造前端 stock 列表页与详情页，详情读态改为 markdown 文章渲染，编辑态改为提交新结构。
4. 同步 stock API 文档并完成真实构建验证。

## 执行流程

1. 阅读任务文档、API 规范入口与仓库记忆，定位到 `backend/src/routes/stock.js`、`backend/src/services/stockStore.js`、`backend/src/models/StockReview.js`、`frontend/src/pages/StockReviewPage.jsx`、`frontend/src/pages/StockReviewDetailPage.jsx`。
2. 将后端 stock 模型从旧的 `topSectors/news/focusStocks` 平铺结构切换为 `markets/todayHot/news/focusSectors/focusStocks/title/content` 新结构。
3. 在后端创建/更新/列表/详情路径中加入 `title` 与 `content` 自动生成逻辑，并在读取时对缺失字段进行回填并写库。
4. 将 `GET /stock/reviews` 和 `GET /stock/reviews/:id` 改为游客可访问，保留写接口和全量列表接口的权限控制。
5. 将前端复盘列表页改为公开访问，并适配新字段 `title`、`content`、`todayHot.topSectors`、`markets.summary`。
6. 将前端复盘详情页读态改为 markdown 文章渲染；编辑态重构为提交新的 `markets/todayHot/news/focusSectors/focusStocks` 结构，并修复 `/stock/review/new` 创建模式识别问题。
7. 同步 `doc/apis/stock.md` 与 `doc/apis/README.md`，确保接口说明与当前实现一致。
