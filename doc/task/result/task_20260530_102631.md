# 股票模块开发任务归档

## 任务来源

- 任务文档：`doc/task/stock_module_new.md`
- 任务目标：完成股市复盘模块的前后端实现、权限接入、接口文档和基础验证。

## 任务计划

1. 实现后端 `stock review` 数据模型、服务层和路由。
2. 将股票复盘权限加入权限目录，并接入后端入口。
3. 实现前端股票复盘页面，提供列表、详情和权限内的创建/编辑/删除能力。
4. 将页面路由和站内入口接入现有导航。
5. 编写 `doc/apis/stock.md` 接口文档。
6. 完成构建校验、数据层真实链路校验和 HTTP 级别鉴权校验。

## 执行流程

1. 阅读任务文档，确认首期只实现“股市复盘”，不展开模拟交易和历史行情缓存。
2. 对照现有 blog、permission、statistics 模块，确定采用独立后端切片 + 单页前端工作台的实现方式。
3. 新增后端模型 `backend/src/models/StockReview.js`，定义复盘对象和四类子对象结构。
4. 新增后端服务 `backend/src/services/stockStore.js`，实现字段规范化、条件查询、分页、CRUD 和唯一日期校验。
5. 新增后端路由 `backend/src/routes/stock.js`，提供分页查询、全量查询、详情、创建、更新、删除接口。
6. 更新 `backend/src/services/permissionConstants.js`，加入 `stock:review:view`、`stock:review:view_all`、`stock:review:create`、`stock:review:update`、`stock:review:delete`。
7. 更新 `backend/src/index.js`，将股票模块挂载到 `/api/stock`。
8. 新增前端服务 `frontend/src/services/stockApi.js`，封装股票复盘接口。
9. 新增页面 `frontend/src/pages/StockReviewPage.jsx`，实现筛选、分页、列表、详情、创建、编辑、删除。
10. 更新 `frontend/src/App.jsx` 和 `frontend/src/components/UserAccountMenu.jsx`，接入路由与入口。
11. 新增接口文档 `doc/apis/stock.md`。
12. 进行构建验证和真实运行路径验证，并清理临时进程与临时数据。
