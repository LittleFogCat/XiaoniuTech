## 执行流程

### 1. 用户权限模块

- 新增 usergroup、blacklist 数据模型，并在 users 表中增加 groups 字段。
- 实现 permissionConstants、permissionStore、permission 路由，支持用户组管理、权限管理、黑名单管理、权限目录查询。
- 将认证中间件改为异步权限注入，`req.user` 中追加 userId、email、nickname、groups、permissions、blacklist 信息。
- 将博客写入类接口、聊天 CRUD、统计查看/导出、聊天管理接口切换到 `requirePermission(...)`。
- 在应用入口增加全局可选鉴权黑名单拦截，确保携带 token 的跨模块请求都会先经过黑名单拒绝。
- 新增前端权限管理页 `/permissions`，并在用户菜单中增加入口。

### 2. 博客自动保存

- 在 blogposts 表中新增 autosave 子文档。
- 后端新增 `PUT /api/blog/posts/:slug/autosave`，并在正式保存文章时清空 autosave。
- 前端 MarkdownEditor 增加 1 秒防抖自动保存状态机。
- 新建文章自动保存到 localStorage；编辑已有文章自动保存到后端，并在重新进入编辑页时优先恢复 autosave 内容。

### 3. 数据统计模块

- 新增 visit_statistics 表与 statisticsStore，支持 enter/exit、概览、趋势、来源、页面、访客、地域以及 CSV 导出。
- 新增 `/api/statistics/enter`、`/api/statistics/exit`、`/api/statistics/overview`、`/api/statistics/export`。
- 前端新增 StatisticsTracker 全局埋点组件与 `/statistics` 页面。
- 在用户菜单中增加访问统计入口，并按权限控制可见性。

### 4. 聊天管理模块

- 新增 chat_model、agent、agent_tool、agent_task、agent_task_step 数据模型。
- 新增 modelStore 与 agentStore，将 models.json / identities 种子数据初始化到数据库。
- 新增聊天管理接口 `/api/chat-management/models` 与 `/api/chat-management/agents`。
- 新增前端聊天管理页 `/chat/manage`，支持模型与智能体的可视化增删改。
- 聊天运行时切换为从数据库读取模型与智能体目录，`/api/models`、`/api/identities` 返回数据库内容。
- 聊天页新增 free 标识展示，并对付费模型/付费智能体做前端选择限制与后端权限兜底。
- 流式聊天请求补发 Authorization 头，确保登录用户的付费聊天权限能在 `/api/chat` 生效。
