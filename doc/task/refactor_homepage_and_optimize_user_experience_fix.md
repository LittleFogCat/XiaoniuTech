# 后续问题的修复和优化

## 首页Hero部分优化

- 标题“XiaoNiu Tech”文字以及“Digital Workspace”文字修改为不可选中的样式。

- 副标题“把聊天、写作、实验与个人工具收束到一个更清晰的数字工作台。”意义不明。你要记住这是一个个人网站，你应该修改为合适的副标题。

- 去除左侧下方的“从 AI 对话到技术写作，...”卡片。

- 去除右侧第二张卡片的“Profile”行。

- 右侧最下方的卡片意义不明？可以添加一些动效，例如行星围绕恒星旋转，鼠标hover时有散落的交互效果，点击时生成彗星效果。当然，这只是我的个人偏好，你可以根据实际情况进行调整。


## 登录UI逻辑统一

用户登录之后，各页面（包括首页和Chat） Header 上的登录逻辑统一改为与博客页面相同。即：登录之后，显示头像，Hover时弹出下拉菜单。

## 浅色模式优化

浅色模式下，首页卡片Hover时的背景色过深，需要调整为浅色。

## 布局异常

首页 Footer 子项目排布异常。应纵向居中，且横向有适当padding。

## identity相关

identities中，需要解耦name与role。例如，“产品策划师若川”，应该解耦为：role = 产品策划师，name = 若川。
