# 用户权限模块

## 1. 任务描述

设计并实现一个用户权限系统。

## 2. 功能描述

### 2.1 用户权限

用户权限指用户执行某项操作时的权限。用户的权限来自于其所属的用户组。
用户权限格式为：`模块:操作`。例如，`blog:read`、`blog:write` 分别代表用户是否有读取博客和写入博客的权限。

### 2.2 用户组

用户组是一个包含了若干用户的组别。用户组拥有特定的用户权限，组中的用户将被赋予组的权限。
一个用户可以隶属于多个用户组。用户的权限将根据其所属的用户组进行合并。

系统用户组列表如下：

|用户组|名称|描述|
|--|--|--|
|user|普通用户|默认用户组，包含基本权限。|
|admin|管理员|拥有除了任命管理员外的所有权限。|
|owner|网站所有用户|拥有网站所有权限，且组成员唯一。|

### 2.3 权限管理

拥有权限管理权限的用户可以对用户权限进行管理。

### 2.4 黑名单

黑名单独立于用户权限。黑名单用户访问任何模块时，都会被拒绝访问。
黑名单机制优先于用户权限。对于黑名单用户，所有操作都返回 403 错误，不再进行权限校验。

## 3. 详细设计

### 3.1 权限列表

|blog|read|读取博客|是|
|blog|write|写博客|是|
|blog|delete|删除博客|是|
|blog|update|更新博客|是|
|blog|manage|管理他人博客|否|


#### 3.1.2 聊天模块权限

|模块|操作|描述|普通用户权限|

### 3.2 前端设计

前端需要提供一个权限管理界面，供拥有权限管理权限的用户进行用户权限的管理。该界面需要包含以下功能：
1. 用户组管理：查看用户组列表，添加用户组，删除用户组，更新用户组信息（名称、描述、成员）。
2. 权限管理：查看用户组权限，更新用户组权限。
3. 黑名单管理：查看黑名单用户，添加用户到黑名单，将用户从黑名单中移除。

### 3.3 后端设计

#### 3.3.1 接口设计

后端新增权限相关接口：

- GET `/api/perm/usergroup`：查看用户组权限，返回用户组列表和权限信息。
- POST `/api/perm/usergroup`：添加用户组，接受用户组名称、描述和成员列表。
- DELETE `/api/perm/usergroup/{group_id}`：删除用户组，接受用户组 ID。不可删除 `isSystem` 为 true 的用户组。
- PUT `/api/perm/usergroup/{group_id}`：更新用户组信息，接受用户组 ID、名称、描述和成员列表。对于 `owner` 组，需强制校验成员的唯一性。
- PUT `/api/perm/usergroup/{group_id}/perm`：更新用户组权限，接受用户组 ID、权限列表。
- GET `/api/blacklist`：查看黑名单用户，返回黑名单用户列表。
- POST `/api/blacklist/{user_id}`：添加用户到黑名单，接受用户 ID。
- DELETE `/api/blacklist/{user_id}`：将用户从黑名单中移除，接受用户 ID。

所有接口均需鉴权，只有拥有对应权限的用户才能调用，否则返回 403 错误。

**权限修改限制**：

1. 用户组无法修改自身权限；
2. 用户组只能修改权限为自身权限子集的用户组的权限；
3. 用户组只能为其他用户组赋予自身已有的权限。

```json
{
  "_id": {
    "$oid": "69f8909222bee8f382afb587"
  },
  "key": "user",
  "name": "普通用户",
  "description": "默认用户组，包含基本权限。",
  "permissions": [
    "blog:read",
    "blog:write",
    "blog:delete",
    "blog:update"
  ],
  "isSystem": true,
  "createdAt": {
    "$date": "2023-08-01T00:00:00Z"
  },
  "updatedAt": {
    "$date": "2023-08-01T00:00:00Z"
  }
}
```

更新 `users` 表：

1. 移除 `role` 和 `priority` 字段，统一通过用户组来管理用户权限。
2. 新增 `groups` 字段，用于存储用户所属的用户组 ID 列表。

```json
{
  "groups": [
    "69f8909222bee8f382afb587",
    "69f8909222bee8f382afb588"
  ],
  // ...
}
```

## 验收标准

1. 权限系统设计合理，能够满足上述功能描述中的权限需求。
2. 权限系统实现正确，能够正确地控制用户的访问权限。
3. 权限系统具有良好的扩展性，能够方便地添加新的权限和用户组。
4. 权限系统具有良好的安全性，能够防止权限绕过和权限提升攻击。
