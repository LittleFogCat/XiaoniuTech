博客模块存在以下问题：
1. 每次浏览一篇文章时，阅读量+2，应该是+1；
2. markdown 渲染问题（这个问题是全项目的 markdown 的通用问题，而非博客模块专属）：
2.1 代码块、超链接与普通文字格式相同，无法区分。
2.2 分割线与上下两行文字距离过近，影响阅读体验。
2.3 无法解析和渲染图片。
3. 文章草稿问题：
3.1 当新建文章点击“存草稿”按钮，`/post/{article}` 接口会返回404。而编辑已有文章存草稿，则不会返回错误。
3.2 没有入口查看存草稿的文章。我的期望是：存草稿文章其他方面与发布的文章相同，但只有作者可以查看，并且在文章列表和文章详情页打上草稿记号，具体是在标题右上角加上“草稿”的绿地白字角标。
4. ui逻辑问题：
4.1 在没有标签时，主页侧边栏也应该显示标签卡片，而不是隐藏。
4.2 “返回主页”按钮现在只应该在博客首页出现，而文章详情页和文章编辑页不应该出现。
4.3 文章编辑页不显示Header。
4.4 文章编辑页的期望是尽量大的编辑与预览区域。编辑区和预览区不用卡片的形式，而是左右顶格到页面边缘。
4.5 文章编辑页按钮增加“取消”，可以返回前一页面。
