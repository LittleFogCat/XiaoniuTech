# 限制验证码频率

目前注册时的验证码可以无间隔发送，这会导致验证码被滥用。
需要限制验证码频率。

当发送验证码之后，开始计时，1分钟之后才能发送下一个验证码。这个计时需要显示在ui。
另外，一小时只能，同一ip最多发布5次验证码。超出的将禁止发送，并提示错误。

# 导入文章

新增导入文章功能。

博客页面，右上角“写博客”按钮改为“创作”按钮。
当鼠标悬浮在按钮上，将显示下拉菜单；下拉菜单包括“写博客”、“导入文章”。直接点击按钮，等同于点击“写博客”。

导入文章说明如下：
- 点击“导入文章”按钮，将弹出选择文件的对话框。
- 支持多选及选择文件夹。
- 仅支持 `.md` 文件。

# 文件系统优化

## markdown 图片自动转换

在发布文章或导入文章时，自动检测文章中是否引用了图片。
如果文章中的图片引用了外链，则下载这个图片到本地文件系统，并存表。同时将文章中的图片链接替换为本地链接。

## 文件重复检测

文件新增 md5 字段，并更新相关 api。
md5、size、mime type 均相同的文件，视作是重复文件。
当上传文件时，如果数据库中已存在相同的文件，则视作文件重复，无需再次上传。

后端启动时，进行低优先度的后台任务，将文件表中无 md5 字段的旧记录计算并添加 md5 字段。

## 新增文件引用表

新增文件引用表，用以记录文件的引用记录。

文件引用表字段：
```
{
  "_id": ObjectId,

  "fileId": "...",          // 对应 files.id
  "refRecord": [
    {
        "bizType": "user_avatar", // 业务类型（强烈建议有）
        "bizId": "123",           // 业务ID（用户ID / 文章ID等）

        "createdAt": 创建时间,
        "updatedAt": 更新时间
    },
    { .. }
  ]
}
```

当用户上传、更新或删除头像时，需要在文件引用表中更新头像文件的引用记录。
当用户发布、导入或删除文章时，需要在文件引用表中更新文章中引用的图片文件的引用记录。

之后涉及到文件的所有操作，如非特殊说明，都需要在文件引用表中更新文件的引用记录。这一点需要记录在记忆文件中。
