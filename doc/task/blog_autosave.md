# 博客自动保存

博客自动保存模块是指在用户写博客时，系统会自动保存用户正在编辑的博客内容，避免用户因为操作失误导致的内容丢失。

## 功能描述

在用户新建或编辑博文的时，若进行了内容的修改，系统会自动保存用户正在编辑的博客内容。用户再次打开该博文时，系统会自动加载用户保存的内容。

## 详细设计

### 后端

博客模块新增 `autosave` 接口，用于自动保存用户正在编辑的博客内容。

```json
{
  "blog_id": "123456",
  "title": "新标题",
  "tags": ["新标签"],
  "content": "新内容"
}
```

`blogposts` 表新增 `autosave` 字段，用于存储用户正在编辑的博客内容。

### 前端

自动保存的触发时机：用户编辑了文章，且停止编辑 1 秒后。

1. 新建博文：对于新建博文，自动保存时直接将标题、标签、内容等字段保存在 localStorage 中，而无需调用后端接口。当意外退出浏览器，再次新建博文时，自动加载自动保存中的内容。当发布或者存草稿成功后，删除 localStorage 中的自动保存内容。
2. 编辑博文：编辑已存在的博文，自动保存时将调用 `autosave` 接口，更新后端数据。再次进入该博文的编辑页面时，系统会自动加载用户保存的内容。当发布或者存草稿成功后，删除后端数据中的自动保存内容。
