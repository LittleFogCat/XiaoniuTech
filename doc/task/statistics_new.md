# 数据统计模块

## 1. 背景描述

目前仅首页（`../../frontend/index.html`）中其嵌入了百度统计的脚本进行访问统计。
在保留百度统计的脚本基础上，新增统计模块，用于展示网站的访问统计。

## 2. 任务描述

对所有页面进行访问统计，包括但不限于首页、博客、聊天等。

当页面加载完毕，会调用接口上报 `enter` 事件。
当页面关闭时（navigator.sendBeacon()），会调用接口上报 `exit` 事件。

## 3. 详细设计

### 3.1 前端设计

统计页面前端路径： `/statistics`。

#### 3.1.1 整体布局

统计模块采用左右布局，左侧为子模块菜单，右侧为统计内容区域。
根据 url 参数，展示不同的统计内容。

#### 3.1.2 统计首页

进入统计模块的默认页面。

页面展示网站的整体访问统计，包括但不限于：

- 浏览量（PV）
- 总访问量（UV）
- 跳出率（Bounce Rate，定义为访问页面仅一次的访问量占总访问量的比例。）
- 平均访问时长

子模块上半部分显示上述数据的今日总览，下半部分显示统计详情卡片（两列 Grid 布局）。每个卡片对应一个子模块，点击卡片右上方的导航图标可以导航至对应的子模块页面。

- 访问趋势折线图：趋势图默认展示 PV，可以切换展示其他指标。
- 访问来源统计，用列表方式展示 top 10 访问来源。
- 受访页面统计，用列表方式展示 top 10 受访页面访问量。
- 访客统计，上半部分展示新老访客占比，下半部分展示对应的浏览量、访客数、跳出率、平均访问时长、平均访问页数。
- 地域分布：根据 IP 地址，用列表方式展示 top 10 地域分布。地域包括各省份、港澳台、海外。

#### 3.1.3 访问趋势子模块

上半部分展示当日的访问趋势折线图，趋势图默认展示 PV，可以切换展示其他指标。
纵坐标为所选指标的值，横坐标为时间，时间间隔为 1 小时。

下半部分展示访问趋势数据表格，表格包含以下列：
- 时间
- PV
- UV
- 跳出率
- 平均访问时长
- 平均访问页数

#### 3.1.4 访问来源子模块

最上方可以选择时间范围，默认展示今日数据。

上半部分展示访问来源饼状图，可选择各种统计指标（PV）。

下半部分展示详细表格，包括各来源的 PV、UV、跳出率、平均访问时长、平均访问页数，以及汇总数据。

#### 3.1.5 受访页面子模块

最上方可以选择时间范围，默认展示今日数据。

根据受访 URL（不含参数），以表格的方式，展示每个受访页面的 PV、UV、跳出率、平均访问时长。

#### 3.1.6 访客统计子模块

最上方可以选择时间范围，默认展示今日数据。

上半部分展示新老访客占比，可选择各种统计指标（PV）。上左显示新访客数据，上右显示老访客数据。新访客定义为 CID 在所选时间范围内首次出现；老访客定义为 CID 在此之前已有访问记录。

其下方用表格的方式展示新老访客的浏览量、访客数、跳出率、平均访问时长、平均访问页数。

再下方根据访问时间，列出访客详情列表，表格包含以下列：

- 时间
- IP 地址（默认隐藏后两位，点击小眼睛图标显示完整地址）
- 浏览量（PV）
- 访问来源

#### 3.1.7 地域分布子模块

最上方可以选择时间范围，默认展示今日数据。

展示地域分布表格，表格包含以下列：
- 地域（省份、港澳台、海外，通过 `ip2region` 库获取）
- 浏览量（PV）
- 访问量（UV）
- 跳出率
- 平均访问时长
- 平均访问页数
- 汇总数据

#### 3.1.8 导出访问统计数据

点击导出按钮，会弹出一个下载对话框，用户可以选择导出的文件范围（今日、本周、本月、本年）。
导出的文件为 CSV 格式，包含以下列：
- 时间
- PV
- UV
- 跳出率
- 平均访问时长
- 平均访问页数
- 汇总数据

### 3.2 后端设计

#### 3.2.1 接口设计

后端新增统计相关接口，接口路径以 `/api/statistics` 开头。

当页面加载时，会生成唯一标识符（CID），并调用接口初始化访问数据。CID 保存在 LocalStorage 中，永久生效，用于进行 UV 的判断。

访问数据包括：
- CID
- 进入时间
- IP 地址
- 访问来源（Referer）
- 浏览器（User-Agent）
- 受访页面

当退出页面时，会上报访问统计数据。
访问数据包括：
- CID
- 退出时间
- 受访页面
- 访问时长

对于长时间（30 分钟）没有接收到 exit 事件的访问数据，会认为是异常访问，设置 `isComplete` 为 false，不进行统计。

接口列表如下：
- `/api/statistics/enter`：页面进入时调用，上报进入时间、IP 地址、访问来源、受访页面。
- `/api/statistics/exit`：页面退出时调用，上报退出时间、受访页面、访问时长。
- `/api/statistics/overview?sub=access_trend`：获取访问统计数据，用于数据展示。根据 `sub` 参数，返回上述不同子模块所需的统计数据结构。
- `/api/statistics/export`：导出访问统计数据，根据 `range` 参数，返回对应的 CSV 文件。

#### 3.2.2 数据库设计

数据表 `visit_statistics`：

```json
{
  "_id": {
    "$oid": "69f8909222bee8f382afb587"
  },
  "cid": "uuid-123456",
  "ip": "192.168.1.1",
  "path": "/chat",
  "referer": "https://www.baidu.com",
  "ua": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)",
  "enterTime": "2026-05-08T10:00:00Z",
  "exitTime": "2026-05-08T10:00:00Z",
  "duration": 300, // 单位：秒
  "isComplete": true // 是否有正常退出上报
}
```

## 4. 验收标准

- 访问统计数据能够正确上报并存储在数据库中。
- 统计页面能够正确展示访问统计数据，并且数据与数据库中的数据一致。
- 统计页面的各项指标计算正确，并且能够根据时间范围进行筛选。
